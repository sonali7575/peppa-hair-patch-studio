BEFORE PUBLISHING
1. Open script.js and replace 91XXXXXXXXXX with the studio's WhatsApp number.
   Use country code and digits only, e.g. 919876543210 (example only).
2. In index.html, update the complete business address, phone number and opening hours once confirmed.
3. Replace gallery placeholders with genuine studio and service photos. Use customer photos only with clear permission.
4. Verify each listed service is actually offered. Edit service descriptions accordingly.
5. Check the Google Maps search result and replace with the exact business pin URL when confirmed.
6. Test all WhatsApp links on desktop and mobile. WhatsApp links open a pre-filled message; they do not store leads or confirm bookings automatically.

PUBLISHING OPTION: GITHUB PAGES
1. Create/sign in to GitHub.
2. Create a PUBLIC repository named peppa-hair-patch-studio.
3. Upload index.html, styles.css and script.js to the repository root.
4. Open Settings > Pages and publish from the main branch, root folder.
5. Test the generated github.io URL before connecting the custom domain.
6. In repository Settings > Pages, add peppahairpatchstudio.com as the custom domain and follow the current GitHub instructions.

EMAIL DNS SAFETY — READ BEFORE CONNECTING DOMAIN
- Do not change nameservers as a shortcut.
- Before editing DNS, take screenshots/export the current GoDaddy DNS records.
- Preserve all existing email-related records: MX, SPF TXT, DKIM TXT/CNAME, DMARC TXT, and any provider-specific verification records.
- Only add/modify website records that GitHub Pages currently specifies. GitHub's DNS instructions can change, so use the exact values shown in GitHub's documentation and UI.
- If GitHub Pages requires apex/root records, add only the required A/AAAA records and verify email records remain untouched.
- Set up and verify the www custom domain if desired; configure the redirect only after both hostnames are working.
- After changes, test inbound/outbound email and website HTTPS.
- DNS changes can take time to propagate. Do not delete MX or mail TXT records.

LIMITATIONS
- This static website has no database, admin dashboard, stored lead form, calendar availability, payments or automated CRM. WhatsApp is the initial booking/enquiry channel.
- Prices are intentionally enquiry-based; no prices or unverified guarantees are invented.
- The visual gallery placeholders are not real photographs or customer results.
